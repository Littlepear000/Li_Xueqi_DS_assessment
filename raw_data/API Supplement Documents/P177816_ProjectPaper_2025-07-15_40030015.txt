  I. PROJECT STATUS AND RATIONALE FOR RESTRUCTURING

1.      Food Systems Resilience Program (FSRP) is a regional program which apply multi-phased approach (MPA).
Multiple countries are part of FSRP program. This is Phase 3 (FSRP3) which includes Africa Union Commission, Kenya,
Somalia, Malawi and Comoros. This restructuring is in relation to Comoros.

2.       Comoros is part of FSRP 3 with IDA US$40 million and PROBLUE Trust Fund (TF) US$3 million. The program in
Comoros focuses on several key components to build resilient agricultural production capacity, support sustainable
development of natural resources, improve market access, and promote food systems resilience in policymaking. Specific
activities include enhancing quality seed systems, livestock sector productivity, resilient fisheries, and digital agriculture
services. Additionally, the program supports resilient landscape and watershed management, water management, and
coastal and marine resources management. Comoros FSRP3 is on track to achieve the Project Development Objectives
(PDO) and has been making significant progress overall.


  II. DESCRIPTION OF PROPOSED CHANGES

3.      This is a restructuring to extend PROBLUE TF closing date from 30-Sep-2025 to 31-Aug-2029 same as all the other
financing sources closing dates of the FSRP3.

4.       Comoros PROBLUE TF closing date was put 30-Sep-2025 because the umbrella PROBLUE Trust Fund closing date
was 31-Dec-2025 during the project preparation. Now the umbrella PROBLUE TF closing date is extended to be 31-Dec-
2029, it allows the linked country-level TF can be extended.

5.    Following this change, the Government of Comoros (GoC) sent an official letter (Letter Number No 24-
001/MFBSB/CAB) requesting the extension of PROBLUE TF (TFC01418-KM) up to 31-Aug-2029.
