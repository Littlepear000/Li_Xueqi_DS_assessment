4.1 Implementation Status and Key Decisions
  The authorization of spending for the project and government's decision on the census, which have been holding up the
  implementation of the project, were provided with the approval of the Presidential Resolution (No. 114) and the Cabinet
  of Ministers Resolution (No. 113) on March 4, 2024. Therefore, the project can now proceed with implementation of
  activities. The PIU is largely in place and the key activities for implementation in the next six months have been identified.

  The project is now being restructured to reflect the change in the implementing agency name and reporting
  arrangements. The restructuring will not change project activities at the moment, in order to focus on getting the project
  implementation up and running first.
