 Implementation Status and Key Decisions

  The combination of political evolutions in January and September 2022, and static approaches to project implementation by the PIUs at a time of
  deteriorating security context has adversely impacted the project.
  The procurement for key consultancy field works received very limited interest from prospective consultants because of the insecurity. A more agile
  project implementation is being developed focusing on: i) a geographically phased approach entailing moving the work/project implementation
  where security permits, ii) deploying as much of the activities as useful within the secured areas, iii) implementation of some of the activities by the
