 Project Development Objectives

  Project Development Objective (from Project Appraisal Document)
  To improve access to broadband services in targeted rural communities and promote the use of digital solutions to improve efficiency of selected
  value-chains, financial inclusion and access to markets.

  Has the Project Development Objective been changed since Board Approval of the Project Objective?
  No
