 Implementation Status and Key Decisions

  This is the initial Implementation Status and Results Report for the Project. There has been a delay in Effectiveness due to the state of emergency
  which was declared for COVID-19, as well as a Cabinet reshuffle in October. Preparatory activities are ongoing, including contracting for the
  Project Coordination Unit and preparation of the Operations Manual.
