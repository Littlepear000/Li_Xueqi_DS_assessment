 Project Development Objectives
  Project Development Objective (from Project Appraisal Document)

 Implementation Status and Key Decisions
  The project was declared effective on December 21, 2018. PFM Reform Project Launch Workshop held on December 5-6, 2018. All major
  procurements have been initiated since then and contracts have commenced implementation. Overall the progress is satisfactory, assessed based
  on a desk review. The first implementation support mission is planned from July 29- August 02, 2019.
