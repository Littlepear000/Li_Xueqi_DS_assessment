 Implementation Status and Key Decisions
  The Project Financing Agreement was signed on August 21, 2018. The Project is not yet effective. The Project is scheduled to become effective on
  or about December 19, 2018. The Permanent Secretariat of the PNADES is responsible for implementing the project under the guidance and
  supervision of the Project Review Committee. There are six conditions to be achieved prior to declaring the Project effective.
