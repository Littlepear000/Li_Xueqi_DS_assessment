 Implementation Status and Key Decisions

  PROCIENCIA and CONCYTEC have been highly active in preparing and implementing project activities since receiving funding in January 2023.
  These include preparing Terms of Reference and/or technical specifications for a large number of consulting and non-consulting services, many of
  which have already been awarded and are under implementation.
  Examples of key advancements include:
          Institutional alliances for Ph.D. program grants. The call for proposals was launched and grantees selected for the first phase. Grantees
           for the second phase are expected to be selected later this year.
          Lab strengthening grants. The call for proposals was launched and applications are currently under review.
