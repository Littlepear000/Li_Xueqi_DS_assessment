 Project Development Objectives

  Project Development Objective (from Project Appraisal Document)
  The Project Development Objectives are to control the desert locust outbreak, support livelihoods in locust-affected areas and strengthen Yemen’s
  preparedness for future locust infestations.

  Has the Project Development Objective been changed since Board Approval of the Project Objective?
  No

 Implementation Status and Key Decisions

  The project became effective in July 14, 2020 and the first disbursement is expected to take place by the end of October 2020. The preparation of
