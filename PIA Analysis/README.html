1. What this is

PIA Analysis is a local web app that reviews World Bank project appraisal documents and extracts their digital & AI innovation approaches. It runs entirely on your computer in a private Python environment and opens in your browser; nothing is deployed to a server. You drive the workflows and review the results yourself.

2. Requirements

  • Windows 10 or 11.
  • Python 3.10, 3.11 or 3.12 with the py launcher (from python.org; tick "Add python.exe to PATH" and keep the py launcher during install). 3.11 is preferred.
  • Internet access (to install packages and to call the Anthropic API).
  • An Anthropic API key (entered later on the Setup page, not stored in any file you ship).
Conda is not used. Setup builds a private .venv inside this folder and never touches your conda or global Python.

3. Install

Unzip this package anywhere (a path with spaces such as PIA Analysis is fine), then double-click setup.bat.

setup.bat finds Python 3.10-3.12, creates a private .venv\ inside this folder, installs the pinned dependencies and the piaa package into it, and creates config\local.env. When it finishes it prints Setup complete - PIA Analysis 0.3.24. The .venv belongs only to this folder; deleting the folder removes everything.

Double-click:  setup.bat

4. Start

Double-click start.bat. It uses only the private .venv (never your global Python). Your browser opens at:

http://127.0.0.1:18765

Keep the black terminal window open while you work. In that window: R + Enter restarts the app after an update; Q + Enter or Ctrl+C stops it. If port 18765 is busy, the next free port (up to +10) is used and the real address is printed in the window.

5. First-time configuration

Open the Setup page in the app and set:

  • API key - your Anthropic key (Provider = Anthropic). It is stored in the local app database, not in any shipped file.
  • raw_data folder - the folder with projects.csv and documents\.
  • output folder - where results, the database and exports are written.

Click Save, then Test connection (you want "OK").

Documents. Put your projects.csv and documents\\ into the raw_data folder. If a project's documents are missing, the app fetches them from the public World Bank Documents & Reports API during a run and stores them in output\\supplement_documents\\ (no API key needed for that). Set PIAA_ACQUIRE=0 in config\\local.env to turn auto-fetch off.

6. Update to a new version

  1. Stop the app (Q + Enter, or close the terminal window).
  2. Unzip the new version over this folder. Your output\ and config\local.env are kept.
  3. Double-click setup.bat again - it updates .venv in place without touching your data.

7. Change the port

Edit config\local.env and set PIAA_PORT, e.g.:

PIAA_PORT=18800

Order of precedence: a PIAA_PORT environment variable > config\local.env > the default 18765. If the chosen port is busy, the app automatically tries the next ports up to +10 and prints the address it used.

8. Uninstall / clean up

Double-click uninstall.bat to delete the private .venv only; your output\, config\local.env and data are kept.

If you previously installed piaa into a global or conda Python, remove it there:

python -m pip uninstall piaa -y
python -m pip check

Do not mass-uninstall the leftover dependencies. If it lived in a dedicated conda environment, remove the whole env:

conda env remove -n your-env-name

9. Folder layout

PIA Analysis\ setup.bat install / update the private environment start.bat run the app (uses .venv only) uninstall.bat remove .venv (keeps data) requirements.lock.txt pinned runtime dependencies pyproject.toml package definition README.html this guide config\ local.env.example template (shipped) local.env your settings (created by setup.bat; kept on update) piaa\ the Python package (code, workflows, web app) .venv\ private environment (created by setup.bat; not shipped) ..\raw_data\ projects.csv + documents\ (default location) ..\output\ database, results, exports (default location)

10. Troubleshooting

SymptomFix
"Python 3.10-3.12 not found"Install Python 3.11 from python.org with the py launcher and "Add to PATH", then re-run setup.bat.
start.bat says ".venv not found"Run setup.bat first (double-click it).
Port busyThe app auto-picks the next free port (up to +10) and prints the address. To fix a port, set PIAA_PORT in config\local.env.
Browser does not openOpen the address printed in the terminal manually, e.g. http://127.0.0.1:18765 .
API errors / Test connection failsCheck the API key and Provider on the Setup page; confirm internet access and that the key is an Anthropic sk-ant-api03- key.
Wrong version shownStop the app, run setup.bat again, then hard-refresh the browser (Ctrl+F5).
A pinned dependency fails to installOpen requirements.lock.txt and relax that one line (e.g. change == to >=), then re-run setup.bat.
