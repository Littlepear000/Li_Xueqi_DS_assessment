Verbatim guarantee

The model only proposes an evidence sentence; piaa.documents.locate_span finds it in the file (exact → whitespace-insensitive → fuzzy ≥ 0.85) and the stored text is always the file's own characters at the stored offsets. Approaches whose sentence cannot be located are dropped and logged in the trace.

Replication logic

  1. Explicit reference: the project's documents mention another in-scope P-code or another in-scope project's name near replication language (builds on, replicates, scales, lessons from, parent project, additional financing).
  2. Similar approach: TF-IDF cosine similarity between this approach (name + description + evidence) and every approach already stored for other projects; links above the threshold are kept with the score. Direction is derived from approval dates (earlier project = origin).

The scan is incremental: each new project is compared against whatever is already in the store, so the whole portfolio does not need to be re-run when one project is added. A final pass over the store (piaa.replication.rescan) refreshes links once all projects are in.
