Workflow v2 - DDAT sentence coding

Implements Methodology Note 1: Approach Definition and Coding Rules and Note 2: Category Definition and Mapping Rules. An approach is one of the 21 second-level themes of the World Bank Theme Taxonomy (June 2025) under 250000 Digital Transformation and 270000 Data Ecosystem; every coded row rests on one verbatim sentence.

Quality control

Run the workflow twice (Run A, Run B) with the same files, prompts and model; piaa compare matches rows on (document, sentence position, approach code), flags rows present in one run only, with a different evidence level, or excluded in one run and kept in the other, samples 5% of agreed rows for spot checks and reports agreement per approach. Flags are settled by a reviewer in the web app.

Speed

16 projects in parallel; within a project classification batches run 4 at a time; the ~80K-character taxonomy block is sent as a cached system prompt so it is billed once per 5 minutes rather than per call.
