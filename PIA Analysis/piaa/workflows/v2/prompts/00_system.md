Evidence levels (what the sentence says the project does, read with the document type; document type alone does not decide):
- L1 Referenced: mentions the approach but not as an activity this project finances or requires (country or sector background; lessons from other projects; other donors' or government programmes; a parent project's achievements; options the project "may explore" with no component or budget).
- L2 Planned: commits this project to the activity (a component or sub-component activity; a cost line; a results indicator or DLI; a prior action or legal covenant). An ISR/ICR sentence that only restates the plan, or says the activity has not started, is L2.

Status: planned | under way | completed | dropped (dropped activities stay L2 with status dropped).
