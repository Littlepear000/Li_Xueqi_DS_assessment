 Project Development Objectives

  Project Development Objective (from Project Appraisal Document)
  The Project Development Objective (PDO) is to increase flood resilience and access to urban infrastructure in selected neighborhoods and to
  improve urban management in Liberia.

  Has the Project Development Objective been changed since Board Approval of the Project Objective?
  No

 Implementation Status and Key Decisions

  The project is completing a drainage cleaning activity under Component 1 (Climate Resilient Infrastructure and Urban Upgrading). The project is
  making progress with Component 2 (Strengthening Integrated Resilient Urban Development Capacity) with the recruitment of integrated advisors for
  capacity building and an upcoming spatial development planning activity. Discussions for strengthening Liberia's urban planning curriculum are
  ongoing as well.

                                        requested additional capacity building support and they have started to develop concepts in this regard,
                                        which will start implementation within the next months.
