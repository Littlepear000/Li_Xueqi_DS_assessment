PIA Analysis

Windows / macOS · Python 3.11, 3.12 or 3.13 · Anthropic API key

No Python yet? (click to expand)

Install Python 3.11, 3.12 or 3.13 from python.org. On Windows, tick Add python.exe to PATH and keep the py launcher during install. Conda is not needed. If Python is already installed, skip this.

1

Start

Double-click start_pia.bat (Windows) or start_pia.command (macOS). The first run builds a private environment and installs everything automatically (one time, a few minutes); after that it just launches. Your browser opens at http://127.0.0.1:18765. Keep the window open: R = restart, Ctrl+C = stop.

2

Setup page

Set the Anthropic API key, and the raw_data and output folders → Save → Test connection.

Use an account API key that starts with sk-ant-api03- (created in the Anthropic Console → API Keys). Do not use a sk-ant-usr- key — that is a user/session token and will fail with 401.

3

Add your data

Put projects.csv and documents\ into raw_data\. Missing project documents are fetched from the World Bank API automatically during a run (into output\supplement_documents\).

4

Run

Approach Spot → pick projects (From database, optional random/first subset), pick a workflow, set how many run in parallel → Extract.

5

Review

Check each project's approaches; edit if needed; Push to database to sign off.

6

Export

Database → Export → one Excel with two tabs: Projects and Approaches.

Port busy → the next free port (up to +10) is used; the real URL prints in the window. Change it with PIAA_PORT in PIA Analysis\config\local.env.
